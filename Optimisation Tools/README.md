# Aerodynamic Optimisation Tools

This framework is based on the CFD optimisation system originally
developed by Spencer Clifford as part of his MEng Individual Project

Original repository:
https://github.com/spenCliff/DSO


The implementation in this directory has subsequently been adapted
and developed for Formula Student aerodynamic optimisation by the
Aerodynamic Performance Group.

## Original work

The original framework provided automation for:

- Parametric SolidWorks geometry generation
- STAR-CCM+ CFD execution
- Iridis HPC job submission and monitoring
- CFD result extraction
- Bayesian optimisation
- Campaign progress tracking
